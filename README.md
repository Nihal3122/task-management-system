# Task Management System

## Project Overview

A full-stack Task Management Application that allows users to manage their daily tasks efficiently.

## Technologies Used

### Frontend

- React.js
- Tailwind CSS
- JavaScript
- Axios
- React Router DOM
- React Hot Toast

### Backend

- Node.js
- Express.js
- MySQL
- Sequelize ORM
- JWT Authentication

## Features

- User Registration
- User Login and Authentication
- Create Tasks
- View Tasks
- Update Tasks
- Delete Tasks
- Search Tasks
- Task Priority Management
- Task Status Management
- Dashboard Statistics
- Toast Notifications

## Project Structure

- `frontend/` – React application
- `backend/` – Node.js and Express API
- `database/` – Database SQL files

## Installation and Setup

### Prerequisites

- Node.js and npm
- MySQL
- Git

### 1. Clone Repository

```bash
git clone https://github.com/Nihal3122/task-management-system.git
cd task-management-system
```

### 2. Database Setup

Import `database/schema.sql` into MySQL.

### 3. Backend Setup

```bash
cd backend
npm install
```

Configure your `.env` file using the required environment variables.

Start the backend:

```bash
npm run dev
```

### 4. Frontend Setup

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```
